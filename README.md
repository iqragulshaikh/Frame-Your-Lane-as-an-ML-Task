# Portfolio Build & ML Track (8-Week Program)

Welcome to my portfolio and data science project repository! This repository documents my journey through an 8-week structured program focused on building a high-impact professional portfolio and implementing a machine learning-based data project.

## 🚀 Repository Structure

- `work/notebooks/` - Contains Jupyter notebooks for each phase of the project:
  - `w02_ml_task_framing.ipynb` - Framing the machine learning task, defining targets, success metrics, data unit of analysis, and comparing ML against fixed rules.
- `portfolio/` - Portfolio sitemap, design assets, and code implementations.

## 🛠️ Phases & Progress

- **Foundations & Portfolio Proof Statement:** Defining the core skill, target audience, and primary call-to-action.
- **ML Problem Framing (Week 2):** Structuring a binary classification problem (Fake News Detection system), establishing data frames, and mapping metrics like Accuracy and F1-Score.

## 💻 Tech Stack
- **Python / Data Science:** Pandas, Scikit-Learn, Jupyter Notebooks
- **Web Development / UI:** HTML, CSS, JavaScript, Tailwind CSS, Figma
